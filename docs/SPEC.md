# 진로 아카이브 기능 명세

## 1. 배경과 방향
- 멘티(고2)의 진로개발역량검사에서 직업이해·호기심·유연성·도전성이 낮게 나왔다. 언어(중어중문)에 관심이 있으나 학과·직업이 실제로 무엇을 하는지 잘 모른다.
- 학구열이 높아 "이거 봐봐" 식 정보는 공부에 밀린다. 그래서 **검증된 자료실**처럼, 쉬는 시간에 짧게 열어 보고 스크랩해 두는 형태가 맞다.
- 이전 버전의 '직접 해보는 수행' 대신, 실제 대학 수업·과제와 직무 사례를 **정보 카드로 아카이빙**한다.
- 멘토링(11/7, 11/21)이 끝난 뒤에도 학생이 고3까지 스스로 정보를 쌓아 가는 도구가 되는 것이 목표다.

## 2. 사용자
- 학생 1~2명: 휴대폰으로 둘러보기, 스크랩, 메모, 관심 직업 정리
- 멘토 1명: 학생이 무엇을 보고 모았는지 확인, 학생 삭제

## 3. 정보 구조 (하단 탭 4개)
| 탭 | 내용 |
| --- | --- |
| 홈 | 오늘의 자료 1개(날짜 기반 순환 추천), 이어서 보기(최근 본 3개), 내 서랍 요약(스크랩 수, 관심 직업), 검색창 |
| 아카이브 | 유형별 목록 + 필터 + 검색 |
| 비교 | 학과 2~3개를 나란히 비교 |
| 내 서랍 | 스크랩, 메모, 관심 직업 정리 카드, 플랜 B·C, 탐색 기록 |

첫 화면(로그인 전)과 멘토 화면은 별도.

## 4. 콘텐츠 유형 (`data/content.json`)
| type | 이름 | 예 |
| --- | --- | --- |
| major | 학과 | 중어중문·중국어중국학, 영어영문, 통번역 |
| job | 직업 | 번역가, 관광통역안내사, 무역사무원 |
| case | 대학 수업·직무 사례 | "번역 전공 학부생의 포스트에디팅 프로젝트" |
| video | 영상 | 전과자 학과 편, 학과 홍보영상 |
| resource | 진로 정보 사이트 | 커리어넷, KOCW |

공통 필드: `id, type, title, fields[], summary, points[], lookFor, sources[{label,url}], related[], tags[]`
- `fields`: language, chinese, business, economics, social, humanities, education
- `lookFor`: "보면서(읽으면서) 찾을 것" 질문 1개
- `related`: 다른 항목 id 목록. 상세 화면에서 서로 연결된다
- 유형별 추가 필드는 content.json 참고 (major: courses, careers / job: group, path / video: source, episode)

## 5. 화면별 기능

### 5-1. 첫 화면 (입장)
- 닉네임 + 숫자 4자리 입력 → 처음이면 새로 만들고, 있으면 기록을 불러온다
- 문서 ID: `users/{닉네임_숫자}`
- 첫 입장 때 "내 기록은 멘토 선생님도 볼 수 있어요" 안내와 확인 버튼
- 기기에 기억해서 다음부터는 바로 홈으로
- 화면 맨 아래 작은 연회색 밑줄 글자 '멘토 로그인' (박스·아이콘 없음)

### 5-2. 아카이브
- 상단 유형 탭: 전체 / 학과 / 직업 / 수업·직무 사례 / 영상 / 자료
- 계열 필터 칩(다중 선택), 정렬: 추천순(기본) / 가나다순
- 검색: 제목, 요약, 태그 대상. 한글 초성 검색은 선택 사항
- 목록 카드: 유형 배지, 계열 배지, 제목, 한 줄 요약, 스크랩 아이콘

### 5-3. 상세
- 제목, 유형·계열 배지, 요약, 핵심 포인트(불릿)
- 유형별 블록: 학과(배우는 과목, 졸업 후 진출), 직업(하는 일, 되는 길), 영상(보러 가기 버튼), 사례(무엇을 보여주는지)
- "보면서 찾을 것" 질문 박스
- 출처 목록(새 창 링크). 출처가 없으면 항목을 보여주지 않는다
- 관련 항목 카드(related)
- 하단 고정 바: 스크랩 / 반응(😮 새로웠다 · 🙂 괜찮았다 · 😐 별로) / 메모
- 메모: 자유 글 + "찾을 것" 질문에 대한 내 답(선택). 자동 저장
- 직업 상세에는 '관심 직업에 추가' 버튼

### 5-4. 비교
- 학과 2~3개 선택 → 배우는 과목, 졸업 후 진출, 관련 직업, 관련 영상을 표로 나란히
- 기본 추천 비교 세트: 중어중문 vs 비즈니스중국어 vs 통번역

### 5-5. 내 서랍
- 스크랩: 유형별로 묶어 보기
- 메모: 최신순, 항목으로 이동
- 관심 직업 정리 카드(최대 3개): 하는 일 / 필요한 능력·지식 / 준비 과정 / 관련 학과·과목 / 근무환경 / 미래 전망 / 출처. 각 칸 아래 "이 아카이브에서 찾기" 링크(관련 항목)와 커리어넷 링크. 채운 칸 수 "6개 중 4개" 표시
- 플랜 B·C: 학과·직업·이유, 진로를 바꾸는 경로 메모
- 탐색 기록: 본 항목 수, 계열별로 많이 본 분야, 😮 반응이 많았던 분야, 새로 알게 된 직업(처음 본 직업 상세 수)

### 5-6. 멘토 화면
- '멘토 로그인' → 비밀번호 입력(화면 어디에도 비밀번호를 표시하지 않음, password 타입). 비밀번호는 `.env`의 `VITE_MENTOR_PASSWORD`
- 학생 목록: 닉네임, 마지막 접속일, 스크랩 수, 메모 수, 관심 직업
- 학생 상세: 내 서랍 내용과 탐색 기록을 읽기 전용으로
- 학생 삭제: 작은 빨간 글자 버튼 → 닉네임을 직접 입력해야 활성화 → `users/{id}`와 모든 하위 컬렉션 문서를 하나씩 삭제

## 6. 사용자 데이터 (Firestore, `users/{닉네임_숫자}` 아래)
- 문서 필드: nickname, consentAt, createdAt, lastVisitAt
- `scraps/{itemId}`: createdAt
- `notes/{itemId}`: text, lookForAnswer, updatedAt
- `reactions/{itemId}`: value(wow | ok | meh), updatedAt
- `views/{itemId}`: firstViewedAt, lastViewedAt, count
- `jobCards/{jobId}`: whatTheyDo, skills, preparation, relatedMajors, workplace, outlook, sources, updatedAt
- `planB/main`: options[{major, job, reason}], changePaths
- 보안 규칙: 익명 로그인 포함 로그인 사용자는 users 하위 읽기·쓰기 허용 (사용자 1~2명, 개인정보 없음 전제)

## 7. 콘텐츠 관리
- 항목 추가는 `data/content.json` 편집으로 한다. README에 추가 방법과 필드 설명을 쓴다
- `scripts/validate-content.ts`: id 중복, 필수 필드, sources 1개 이상, related id 존재 여부, URL 형식 검사. `npm run validate`로 실행, 빌드 전에 자동 실행

## 8. 완료 기준
- 휴대폰 크기에서 모든 화면이 가로 스크롤 없이 보인다
- 앱을 닫았다 열어도, 다른 기기에서 같은 닉네임·숫자로 들어와도 스크랩·메모가 유지된다
- 같은 닉네임에 숫자를 다르게 넣으면 다른 사람으로 들어간다
- 멘토 화면에서 학생 기록이 보이고, 삭제하면 같은 값으로 들어갔을 때 빈 기록이다
- `npm run validate`, `npm run build`, `npm run lint` 통과
- 출처 없는 항목, 검사 문항 문장, 개인정보 입력란이 없다
